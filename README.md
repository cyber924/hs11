# 허브스튜디오 11 — 투자분석 스튜디오

한국어 기반 투자·사업분석 업무 플랫폼입니다. Cloudflare Workers와 D1을 사용합니다.

## 현재 구현 기능

- 한국어 로그인·회원가입, 개인별 프로젝트 데이터 분리
- 비밀번호 8~10자 제한(화면과 서버 양쪽에서 검사)
- 투자 딜 등록·수정·삭제 및 단계별 파이프라인
- 프로젝트별 투자 규모, 분야, 소재지, 스폰서 및 사업 개요 관리
- DSCR·LTV·월 상환액·연간 원리금 상환액 간편 계산
- 사업·금융·건설·기술·운영·전력·인허가·시장·계약 위험요인 평가
- 투자심사 메모 저장 및 인쇄·PDF 출력
- Gemini AI 기반 종합 투자심사보고서 자동 초안 생성
- 프로젝트 기본정보·투자심사 메모·기존 위험요인·이전 분석 이력을 통합한 보고서 입력
- AI가 추출한 주요 위험요인을 기존 위험관리 테이블에 자동 등록(중복 항목 제외)
- 잠정 검토의견·추가 자료 요청·선결조건을 보고서 결과 페이지에서 별도 표시
- 보고서 분석 이력 보관, Markdown 다운로드 및 브라우저 인쇄·PDF 저장
- GitHub Actions의 Worker JavaScript 문법 검사

## Cloudflare 연결 및 배포

1. Cloudflare 대시보드에서 D1 데이터베이스를 생성합니다. 권장 이름은 `hubstudio11-db`입니다.
2. Worker `hs11`의 설정에서 D1 데이터베이스 바인딩을 추가합니다.
   - 변수 이름: `DB`
   - 데이터베이스: 방금 생성한 `hubstudio11-db`
   - 환경: 프로덕션
3. D1 콘솔의 SQL 편집기에서 `migrations/0001_initial.sql` 전체를 실행합니다.
4. AI 분석 이력 기능을 적용할 때 `migrations/0002_ai_analyses.sql` 전체를 같은 D1 데이터베이스 콘솔에서 실행합니다.
5. Worker를 배포합니다.
6. AI 심사 보조 분석을 사용할 경우 Worker의 프로덕션 시크릿에 다음을 등록합니다.
   - 이름: `GEMINI_API_KEY`
   - 값: Google AI Studio에서 발급한 Gemini API 키
7. 배포된 주소에서 회원가입 후 프로젝트를 등록해 테스트합니다.

## 종합 투자심사보고서 작성 흐름

1. 투자 딜의 프로젝트명, 분야, 단계, 소재지, 스폰서, 투자규모 및 사업 개요를 입력합니다.
2. 프로젝트 상세 화면의 투자심사 메모에 사업구조, 주요 계약, 매출·비용 가정, 자금조달 및 상환재원 등 확보한 자료를 정리합니다.
3. 위험요인 관리 화면에 이미 파악한 위험과 대응방안을 등록합니다.
4. 프로젝트 상세 화면에서 `AI 심사 쟁점 분석`을 실행합니다. AI는 프로젝트 정보, 심사 메모, 기존 위험요인 및 최근 분석 이력을 참고해 10개 목차의 종합 투자심사보고서 초안을 작성합니다.
5. 추출된 위험요인은 위험관리 화면에 중복을 확인한 후 자동 등록됩니다. 잠정 검토의견, 추가 자료 요청 및 선결조건은 보고서 상세 화면에서 확인할 수 있습니다.
6. 보고서 상세 화면에서 Markdown 파일을 내려받거나 브라우저 인쇄 기능으로 PDF 저장을 할 수 있습니다. 생성된 보고서는 `/analyses`에서 다시 열람할 수 있습니다.

> AI 보고서는 입력된 자료에 기초한 초안입니다. 입력되지 않은 사업·시장·계약·금융 정보는 확인 필요로 표시되며, 사실관계와 수치, 계약 조항 및 법률·세무 쟁점은 원문 자료로 검증해야 합니다. AI가 등록한 위험요인도 담당자가 검토한 후 확정하세요.

> D1 바인딩과 Gemini 키는 저장소에 비밀값을 넣지 않도록 Cloudflare 대시보드에서 별도로 설정합니다. Gemini 키가 없어도 프로젝트 관리, 금융지표 계산, 위험관리 및 심사 메모 기능은 사용할 수 있습니다.

## 비밀번호 정책

회원가입 비밀번호는 10자 이하입니다. 11자 이상은 서버에서 거부합니다.

## 계산 유의사항

금융지표 계산기는 입력한 금액·이자율·기간에 따라 원리금균등상환을 가정한 참고용 수치를 산출합니다. DSCR 및 LTV는 입력 가정에 따른 계산값이며, 실제 약정조건과 금융모델을 대체하지 않습니다. 대시보드에서는 서로 다른 통화의 투자금액을 합산하지 않습니다.
