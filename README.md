# 허브스튜디오 11 — 투자분석 스튜디오

한국어 기반 투자·사업분석 업무 플랫폼입니다. Cloudflare Workers와 D1을 사용합니다.

## 배포 준비

1. Cloudflare D1에 `migrations/0001_initial.sql`을 적용합니다.
2. Worker의 D1 바인딩 이름을 `DB`로 설정합니다.
3. 필요하면 `GEMINI_API_KEY`를 Worker Secret으로 등록합니다. AI 분석 기능에서만 사용하며, 키가 없어도 기본 프로젝트 관리 기능은 동작합니다.
4. GitHub 저장소를 Cloudflare Workers Builds에 연결하고 배포합니다.

## 비밀번호 정책

회원가입 비밀번호는 8~10자이며, 입력 단계와 서버에서 모두 최대 10자로 제한합니다.

## 주요 기능

- 회원가입·로그인 및 개인별 프로젝트 데이터 분리
- 투자 딜 파이프라인과 프로젝트 등록
- DSCR·LTV·대출상환액 등 기초 금융지표 계산
- 사업·금융·계약·건설·운영 리스크 등록 및 평가
- 투자심사 메모 작성과 인쇄용 보고서
- Gemini AI 분석(선택 설정)
